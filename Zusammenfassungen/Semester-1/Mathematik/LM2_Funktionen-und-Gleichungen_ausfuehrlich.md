# 1 Zuordnungen und ihre Darstellungen

## 1.1 Tabelle, Graf, Koordinatensystem
Eine **Zuordnung** verknüpft Größen (z. B. Menge → Preis). Drei Darstellungen:
- **Wertetabelle** (x-Werte und zugehörige y-Werte),
- **Graf** (Punkte/Linie im **Koordinatensystem**: x = Rechtsachse, y = Hochachse),
- **Zuordnungsvorschrift / Term** (z. B. x → 8,3x).

## 1.2 Proportionale und antiproportionale Zuordnungen
**Proportional** ("je mehr – desto mehr"):
- Der **Quotient y/x = k** ist konstant (**Proportionalitätsfaktor**).
- Gleichung: **y = k·x** · Graf: **Gerade durch den Ursprung**.
- Beispiel: 80 Hohlblocksteine wiegen 440 kg → k = 440/80 = 5,5 kg pro Stein → y = 5,5·x.

**Antiproportional** ("je mehr – desto weniger"):
- Das **Produkt x·y = c** ist konstant (**Proportionalitätskonstante**).
- Gleichung: **y = c/x** · Graf: **Hyperbel**.
- Beispiel: 3 Pumpen brauchen 3 h 20 min; mehr Pumpen → weniger Zeit.

## 1.3 Dreisatz
Rechnen über die **Einheit (1)**.

**Proportional (Lehrbeispiel Fliesen):** 24 m² kosten 840 €, wie viel 7 m²?
1. 24 m² → 840 €
2. 1 m² → 840 : 24 = **35 €**  *(erst dividieren)*
3. 7 m² → 35 · 7 = **245 €**  *(dann multiplizieren)*

**Antiproportional (Maschinen):** 4 Maschinen → 3 h. Wie lange 3 Maschinen (gleiche Stückzahl)?
1. 4 Maschinen → 3 h
2. 1 Maschine → 3 · 4 = **12 h**  *(erst multiplizieren, weniger Maschinen = mehr Zeit)*
3. 3 Maschinen → 12 : 3 = **4 h**  *(dann dividieren)*

> Merke: proportional = **: dann ·** · antiproportional = **· dann :**.

## 1.4 Äquivalenzumformungen (Gleichungen & Ungleichungen)
Eine **Aussage** ist wahr (w) oder falsch (f) ("Köln liegt am Rhein" = w · "2,5 ist eine ganze Zahl" = f). Eine **Aussageform** (mit Variable) wird durch Einsetzen zur Aussage. Die **Lösungsmenge L** enthält alle Einsetzungen, die die Aussageform *wahr* machen.

**Äquivalenzumformung:** Auf **beiden Seiten dasselbe** rechnen — die Lösungsmenge bleibt gleich. Erlaubt: + / − dieselbe Zahl, · / : durch dieselbe Zahl (≠ 0).

**Lehrbeispiel lineare Gleichung:** 3x − 5 = 7
1. `+5` auf beiden Seiten → 3x = 12
2. `:3` → **x = 4** · Probe: 3·4 − 5 = 7 ✓

**Ungleichungen:** genauso — **aber** bei **Multiplikation/Division mit einer negativen Zahl dreht sich das Vergleichszeichen um**.
- Beispiel: −2x < 6 → `:(−2)` → **x > −3** (Zeichen gedreht!).

# 2 Funktionen als eindeutige Zuordnungen

## 2.1 Definitionsmenge und Wertemenge
Eine **Funktion** ist eine **eindeutige** Zuordnung: jedem x-Wert ist **genau ein** y-Wert zugeordnet.
- **Definitionsmenge D:** alle erlaubten x-Werte (z. B. D = {x | 0 ≤ x ≤ 10}).
- **Wertemenge W:** alle vorkommenden y-Werte.
- Schreibweisen: `f: x → 8,3x` oder `y = 8,3x` oder `f(x) = 8,3x`.

## 2.2 Funktionen im Koordinatensystem – die Gerade
**Lineare Funktion / Geradengleichung:**

> **y = m·x + b**

- **m = Steigung** = Δy/Δx (Höhenunterschied je Schritt nach rechts). m > 0 steigend, m < 0 fallend.
- **b = y-Achsenabschnitt** (Schnittpunkt mit der y-Achse, dort x = 0).
- Sonderfall b = 0 → **Ursprungsgerade** y = m·x (das ist die proportionale Zuordnung).

**Lehrbeispiel (Messing):** Dichte 8,3 g/cm³, Zuordnung Volumen → Masse. k = 8,3 → **y = 8,3x**. Wertetabelle: x = 1 → 8,3 · x = 2 → 16,6 · … · x = 10 → 83,0. Graf: Ursprungsgerade mit Steigung 8,3.

**Zeichnen aus y = mx + b:** Punkt (0, b) markieren, von dort mit der Steigung m (z. B. m = 2: 1 nach rechts, 2 nach oben) den zweiten Punkt setzen, Gerade ziehen.

## 2.3 Nullstellen und Schnittpunkt
- **Nullstelle:** Schnittpunkt mit der x-Achse → dort ist **y = 0**. Aus 0 = m·x + b folgt **x = −b/m**.
  - Beispiel: y = 2x − 6 → 0 = 2x − 6 → x = 3 → Nullstelle (3 | 0).
- **Schnittpunkt zweier Geraden:** beide y-Terme **gleichsetzen**.
  - y = 2x − 6 und y = −x + 3 → 2x − 6 = −x + 3 → 3x = 9 → x = 3 → y = 0 → Schnittpunkt (3 | 0).

## 2.4 Lineare Gleichungssysteme mit zwei Unbekannten
Zwei Gleichungen mit x und y. Drei gleichwertige Lösungsverfahren:

**Beispielsystem:** (I) x + y = 10 · (II) x − y = 2.

**a) Gleichsetzungsverfahren** – beide nach derselben Variable auflösen und gleichsetzen:
(I) y = 10 − x · (II) y = x − 2 → 10 − x = x − 2 → 12 = 2x → **x = 6**, y = 4.

**b) Einsetzungsverfahren** – eine Gleichung nach einer Variable auflösen, in die andere einsetzen:
(II) x = 2 + y → in (I): (2 + y) + y = 10 → 2 + 2y = 10 → **y = 4**, x = 6.

**c) Additionsverfahren** – Gleichungen so addieren/subtrahieren, dass eine Variable wegfällt:
(I) + (II): (x + y) + (x − y) = 10 + 2 → 2x = 12 → **x = 6**, y = 4.

> **Lösung: (x | y) = (6 | 4).** Alle drei Wege führen zum selben Ergebnis – nimm das für das System einfachste.

## 2.5 Umkehrfunktionen
Die **Umkehrfunktion** kehrt die Zuordnung um (aus y wieder x). Vorgehen:
1. Funktionsgleichung nach **x auflösen**,
2. **x und y vertauschen**.
- Beispiel: y = 2x + 4 → x = (y − 4)/2 → tauschen → **y = (x − 4)/2**.
- Der Graf der Umkehrfunktion ist die **Spiegelung** des Original-Grafen an der Winkelhalbierenden **y = x**.
