## 1 Quadratische Funktionen
- **Normalparabel** f(x) = x², Scheitelpunkt S(0|0), nach oben geöffnet.
- **Verschiebungen:** f(x) = x² + s → S(0|s) · f(x) = (x − r)² → S(r|0) · **Scheitelpunktform** f(x) = a(x − r)² + s → **S(r|s)**.
- **Allgemeine Form:** y = ax² + bx + c (a ≠ 0). a > 0 nach oben, a < 0 nach unten; |a| > 1 steiler, |a| < 1 flacher. c = Schnittpunkt mit y-Achse.
- **Umwandlung** allgemeine → Scheitelpunktform per **quadratischer Ergänzung**.
- **Quadratische Gleichung** x² + px + q = 0 → **p-q-Formel**: x₁,₂ = −p/2 ± √((p/2)² − q).

## 2 Wurzelfunktionen
f(x) = √x ist die **Umkehrfunktion** von f(x) = x² (für x ≥ 0). Graf: Spiegelung an y = x.

## 3 Potenzfunktionen
- f(x) = xⁿ. **Gerader Exponent** → Parabeltyp (symmetrisch zur y-Achse), **ungerader** → punktsymmetrisch zum Ursprung.
- **Potenzgesetze:** aᵐ·aⁿ = aᵐ⁺ⁿ · aᵐ:aⁿ = aᵐ⁻ⁿ · (aᵐ)ⁿ = aᵐ·ⁿ · a⁻ⁿ = 1/aⁿ · a^(1/n) = ⁿ√a.

## 4 Exponentialfunktionen
- **f(x) = aˣ** – die Variable steht im **Exponenten**. Typisch für Wachstum/Zerfall (Bakterien, Bevölkerung).
- Beispiel: Masse verdreifacht sich stündlich → f(x) = 3ˣ. Graf geht immer durch (0|1), nähert sich der x-Achse.

## 5 Logarithmusfunktionen
- **log_a b = Exponent, mit dem a potenziert werden muss, um b zu erhalten.** (b = Numerus)
  Bsp: log₂ 8 = 3, denn 2³ = 8.
- **Systeme:** lg = log₁₀ (dekadisch) · ln = log_e (natürlich) · ld/lb = log₂ (dual).
- **Basiswechsel:** log_a x = lg x / lg a.
- **Exponentialgleichungen** (Variable im Exponenten) löst man durch **Logarithmieren**:
  6ˣ = 330 → x·lg 6 = lg 330 → x ≈ 3,2365.
