## Runden von Zahlen
**Was:** Eine Zahl auf *n* Nachkommastellen kürzen – so genau wie nötig.
**Regel:** Entscheidend ist die (n+1)-te Stelle. 0–4 → abrunden, 5–9 → aufrunden.
**Beispiel:** 22,747 → auf 2 Stellen → **22,75** (die 7 rundet auf). 9,81 → **9,8** (die 1 rundet ab).

## Zehnerpotenzen
**Was:** Sehr große/kleine Zahlen als „Zahl zwischen 1 und 10 × 10^k" (wissenschaftliche Schreibweise).
**Vorsätze:** k = 10³, M = 10⁶, G = 10⁹ · m = 10⁻³, µ = 10⁻⁶, n = 10⁻⁹.
**Beispiel:** 250 kW = 2,5 · 10⁵ W · 8 µm = 8 · 10⁻⁶ m.

## Zahlenmengen
**Was:** Aufeinander aufbauende Mengen von Zahlen: **ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ**.
| Menge | kommt dazu | Beispiel |
|-------|-----------|----------|
| ℕ | Zählzahlen | 1, 2, 3 |
| ℤ | negative + 0 | −5, 0, 7 |
| ℚ | Brüche | ¾, 0,3̄ |
| ℝ | irrationale | √2, π |
| ℂ | i mit i²=−1 | 3 + 2i |
**Beispiel:** −3 ∈ ℤ, aber −3 ∉ ℕ. √2 ∈ ℝ, aber √2 ∉ ℚ.

## Binomische Formeln
**Was:** Drei Formeln zum schnellen Ausmultiplizieren/Faktorisieren von Klammern.
1. (a + b)² = a² + 2ab + b²
2. (a − b)² = a² − 2ab + b²
3. (a + b)(a − b) = a² − b²
**Beispiel:** (x + 4)(x − 4) = x² − 16. · (15r + 3s)² = 225r² + 90rs + 9s².

## Rechenreihenfolge
**Was:** Reihenfolge der Rechenschritte: **Klammer → Potenz → Punkt (·,:) → Strich (+,−)**.
**Merksatz:** „Punkt vor Strich".
**Beispiel:** 2 + 3 · 4 = 2 + 12 = **14** (nicht 20).

## Faktorisieren
**Was:** Eine Summe in ein Produkt umwandeln, indem man den gemeinsamen Faktor ausklammert.
**Regel:** a·b + a·c = a·(b + c).
**Beispiel:** 6x + 9 = 3·(2x + 3). · x² − 16 = (x + 4)(x − 4).

---

## Polynomdivision
**Was:** Zwei Polynome „schriftlich" dividieren (höchste Potenz zuerst) – etwa um Nullstellen abzuspalten.
**Beispiel:** (x² + 5x + 6) : (x + 2) = **x + 3**.
